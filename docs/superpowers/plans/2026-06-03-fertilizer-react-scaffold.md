# Fertilizer React Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert `react-app/` into a real Vite + React app and build the first fertilizer page with search, category selection, connected local state, and an empty list placeholder.

**Architecture:** Keep the app small and feature-first. Use a thin `App` shell, a single `FertilizerInfoPage` composition module, small presentational components, and one local-state hook so later real data can be added without reshaping the page.

**Tech Stack:** React, React DOM, Vite, Vitest, Testing Library, jsdom, existing `xlsx`

```jsx
export default function CategorySelector({
  categories,
  selectedCategory,
  onSelect,
}) {
  return (
    <div className="fertilizer-categories" role="group" aria-label="카테고리 선택">
      {categories.map((category) => {
        const isActive = category === selectedCategory;

        return (
          <button
            key={category}
            type="button"
            className={isActive ? 'chip chip--active' : 'chip'}
            aria-pressed={isActive}
            onClick={() => onSelect(category)}
          >
            {category}
          </button>
        );
      })}
    </div>
  );
}
```

`react-app/src/features/fertilizer/pages/FertilizerInfoPage.jsx`

```jsx
import { customCategories } from '../config/categories';
import CategorySelector from '../components/CategorySelector';
import EmptyFertilizerList from '../components/EmptyFertilizerList';
import SearchInput from '../components/SearchInput';
import { useFertilizerFilters } from '../hooks/useFertilizerFilters';
import './FertilizerInfoPage.css';

export default function FertilizerInfoPage() {
  const {
    query,
    selectedCategory,
    setQuery,
    setSelectedCategory,
  } = useFertilizerFilters();

  const categoryOptions = ['전체', ...customCategories];

  return (
    <div className="fertilizer-page">
      <header className="fertilizer-page__hero">
        <p className="fertilizer-page__eyebrow">NH-AGri</p>
        <h1 className="fertilizer-page__title">비료 정보</h1>
        <p className="fertilizer-page__description">
          검색과 카테고리 구조를 먼저 고정한 초기 React 화면입니다.
        </p>
      </header>

      <section className="fertilizer-page__search">
        <SearchInput
          value={query}
          onChange={setQuery}
          placeholder="상품명 검색"
        />
      </section>

      <section className="fertilizer-page__categories">
        <CategorySelector
          categories={categoryOptions}
          selectedCategory={selectedCategory}
          onSelect={setSelectedCategory}
        />
      </section>

      <section className="fertilizer-page__list">
        <EmptyFertilizerList />
      </section>
    </div>
  );
}
```
