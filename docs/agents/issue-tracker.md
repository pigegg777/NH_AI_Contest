# Issue tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues for `pigegg777/NH_AI_Contest`.

## Conventions

- Create issues in the current repository rather than in adjacent repos.
- Prefer GitHub connector tools when available.
- If CLI tooling is needed, infer the repository from the local clone.
- Treat a PRD issue as the parent record for any follow-on implementation slices.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `pigegg777/NH_AI_Contest`.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue body and comments from the same repository.
