# Editing Scope Model

The AI treats these units as independent edit targets:

- `page`
- `search`
- `category`
- `cardGrid`
- `card`
- `card.field`

## Scope Meaning

### `page`

Whole-page visual changes.

### `search`

Search box level changes.

### `category`

Medium-category chip area changes.

### `cardGrid`

Card list layout changes.

### `card`

Single-card container changes.

### `card.field`

Individual card data element changes, such as:

- `product_name`
- `spec`
- `tax_price`
- `zero_tax_price`
- `exempt_tax_price`
- `price_subsidy`
