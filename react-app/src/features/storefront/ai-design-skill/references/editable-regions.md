# Editable Regions

## `page`

- background
- width
- top spacing
- section spacing
- overall tone

## `search`

- color
- size
- placeholder
- radius
- border
- icon
- alignment

## `category`

- layout direction
- size
- color
- radius
- gap
- scroll behavior
- row count
- active-chip style

Examples:

- single-row category chips
- horizontal scroll
- stronger active chip

## `cardGrid`

- cards per row
- gap
- background color
- border
- radius
- padding
- section width

Example:

- show one product per row

## `card`

- background
- border
- shadow
- padding
- radius
- image position
- title position
- field order
- field alignment
- field color
- field font
- field size
- field emphasis

## `card.field`

Every card field must be individually editable.

Examples:

- subsidy blue only
- keep tax price default
- bold zero-tax price only
- smaller exempt-tax price only
- reduce spacing between product name and spec
